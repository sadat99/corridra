## Identity and authority

Anonymous; verified/unverified customer; scoped buyer/supplier/client/institution capability; independently invited contributor; owner/admin/operator/reviewer/viewer are separate access classes. Exact authoritative role mappings remain in packages/domain/src/index.ts and per-service withTenant checks. Configuration, current MFA, source rights, capability audience, revocation, expiry, independent review and RLS remain additional conditions. A visible tool is not permission.

## Availability

V1 1–8 and V2 1–5 are implemented. Mission operations remain synthetic. D01–D06 and D08, real outreach, live AI providers and contributor pilots remain externally gated; payments/payout execution is not implemented. Customer identity activation is a separate accepted baseline. No live gate was queried or modified by this collector.

## Reconciliation limitations

Gate 0 discovery includes the generated inventory, immutable master handoff, baseline measurements and verification report. Exhaustive runtime action expansion is not claimed. Runtime action expansion, baseline screenshots, per-action positive/negative linkage, role/state verification and protected workflow execution are tracked separately. Original source documents and domain contracts are unchanged.
