## Implemented contract

`@corridra/intelligence` owns the task registry, policy validation, gateway, provider adapters, persistence and draft review. The twelve registered v1 tasks are commercial intent, requirements, counterparty research, duplicate suggestions, buyer/supplier fit, machinery specifications, quotation comparison, meeting preparation, translation, evidence gaps, follow-up suggestions and opportunity/outcome summaries. Each has a strict input/output schema, prompt version, golden-set identifier, public-text retrieval boundary, human approval and bounded manual fallback.

Only explicitly selected public claims with current approved source rights reach a model. Claims must belong to the tenant, source retention must remain current, reuse and transfer must be approved, and every provider processing country must be allowed. Personal contact text is unsupported. A current explicitly pinned mission pack must reference the reviewed model policy. Source content is quoted untrusted data; model tools, arbitrary retrieval, SQL and business commands are unavailable. Provider SDKs appear only in the adapter module. Structured output uses the installed AI SDK's `generateText` and `Output.object` contracts.

Reviewed provider/model versions are append-only configuration, including secret references, terms/evaluation sources, processing countries, task eligibility, original USD cost rates, budgets, expiry and at most one explicit approved fallback. Switching supported identifiers requires new reviewed configuration and an explicit mission binding, without changing code. Production adapters reject synthetic-only evaluation approval. Missing credentials or provider failures preserve manual work. No actual provider invoice cost or live-model accuracy is inferred from synthetic protocol tests.

Maximum two attempts, a shared 15-second task deadline, 24,000 input bytes, 2,000 output tokens, conservative exact-integer reservations, a per-task total cost ceiling and a tenant daily budget bound inference. Pending/crashed attempts continue to reserve budget; repeating a received command never starts another inference. Persisted provider failure/pending attempts open a short circuit. Error records contain safe codes, not provider request bodies. Every output stays `UNVERIFIED_DRAFT`; factual quotations must match actual source/claim pairs. Accept/edit/reject records human review but executes no commercial command.

`@corridra/network` owns private capability profiles and one country-neutral task engine. Ten categories include diaspora/private connectors, institutional operators, field researchers, interpreters and technical advisers. Profiles bind an explicitly invited MFA principal, reviewed capabilities, markets, work countries, languages, sectors, availability, eligibility source and expiry. No customer email matching, public personal directory, blanket contributor role or constant location tracking is introduced.

Tasks disclose action, actual market/work country/location, language/sector/capabilities, deadline and late cutoff, evidence, effort, data handling, reviewer, conditional reward rule, cancellation and dispute terms before acceptance. Reviewed assignment, acceptance, submission, correction, evidence review, completion/rejection/dispute/cancellation and explicit dispute disposition append immutable events. Contributor access is an exact-assignee disclosure through guarded database functions; it grants no tenant membership or parent mission access. Suspension, identity revocation, expired eligibility and scope changes fail closed. Offline submissions stay in page memory and are clearly unreceived until the same request is acknowledged.

Independent review materializes the actual original declaration using existing source/claim contracts; it does not turn a declaration into a verified fact. Timeliness and evidence-quality dimensions retain category-specific rationale. Verification identifiers must refer to actual current independently verified evidence. Completion supports one existing contribution and a separately approved obligation in the original service ledger. Current disclosed rule, distinct accounting approval, independent reconciliation, uniqueness and exact negative reversals remain enforced. No second balance, payout integration, money guarantee or automated attribution is added.

## Release gates and activation

Both `CORRIDRA_AI_ENABLED` and `CORRIDRA_NETWORK_ENABLED` default closed, independently of tenant flags `ai.enabled` and `network.enabled`. Builds never migrate. Production activation requires accepted provider terms/evaluation/processing-region/credential/outbound prerequisites for AI, and controlled invitation/eligibility/privacy/reward/legal pilot acceptance for network work. This packet does not activate real customer missions, international payouts or automatic commercial messages.

Local browser validation uses a strictly loopback synthetic provider fixture; remote databases and every Vercel environment reject that fixture configuration. Synthetic SDK protocol and golden-schema tests measure orchestration/schema/grounding/policy behavior, not live-model factual accuracy. Vision, file inference, embeddings and streaming are intentionally unavailable on this bounded public-text surface.

Final release evidence belongs in the release record and accepted PR. Earlier failing, interrupted or preparation runs are not acceptance evidence.
