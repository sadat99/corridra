# ADR 057: Real invited execution work

Status: implementation in progress; production activation requires checked source and the protected installation workflow.

The owner requests a working Production Network flag and real contributor work after ADR056 real mission admission. This extends the existing restricted execution module. It does not create a public marketplace, tenant-wide contributor access, automated outreach or a payment provider.

Use an additive optional Network migration after the unchanged core and real-use migrations. Preserve synthetic acceptance. Resolve processing purpose from the selected tenant's recorded provenance; real execution requires established real-use authority and the separately enabled tenant Network control. The environment flag remains independent. Real Network enablement must not enable real AI inference.

An owner/admin with current MFA may prepare an explicit contributor invitation within their country scope. Reuse the existing separate password/TOTP identity and verified-account setup proof. A pending identity remains disabled until the intended verified account completes setup and enrolls its authenticator. Invitations expire and can be revoked; retries cannot reset an existing identity. Contributors receive no membership. An existing active identity may be referenced without changing its credentials or authority.

Only assigned task disclosures are visible to a contributor. Retain current eligibility, capability, country, deadline and relationship checks; independent evidence review, contribution assessment and reward approval remain distinct. Existing exact-money, obligation, reconciliation, reversal and append-only history rules remain authoritative. Review of eligibility does not assert external legal approval. Evidence scanning retains the owner-approved BYPASSED state.

Release evidence must include real and synthetic isolation, invitation ownership/expiry/revocation/retry, existing-identity preservation, MFA/role/country denials, profile suspension, stale task decisions, independent review and exact financial preservation. Exercise invited setup and task submission in the browser with the real application/database. Fixture results do not establish managed email delivery or genuine production identity acceptance.

Deploy checked code with the Network gate closed, install through the protected reviewed workflow, then enable the explicit database/Production controls and verify an exact-source deployment. Pausing Network must preserve identity, private task history and financial records; no data is cleared during rollback.
