# ADR 028: Governed tasks and restricted execution work

Status: implementation in progress for the revised V2 Part 4 packet.

Provider SDKs belong only to the intelligence adapter module. Business services request registered, versioned tasks with explicit evidence identifiers. Retrieval authorization precedes inference. The initial surface supports public, rights-reviewed text only; arbitrary retrieval, file inference, embeddings, model tools and autonomous commands are unavailable. Provider model identifiers and approved policy versions are configuration, not business code.

All output is an unverified draft. Facts must preserve an exact source quotation and a known claim/source pair. Review acceptance approves a draft, never a verified fact, permission, payment, legal decision or commercial command. Existing deterministic commands remain the only authority for consequential changes.

Execution profiles are private, tenant scoped and capability based. Invitations bind an existing MFA identity by principal identifier, never by matching email. A contributor receives only an explicitly assigned task disclosure, not tenant membership or parent mission access. Review and contribution assessment remain separate from independent reward approval and reconciliation. The original service ledger remains the only reward ledger; reversals preserve history.

AI and network enablement are independent and fail closed. Synthetic validation does not establish legal work eligibility, international payment readiness or real inference quality. No real customer operation is enabled by this decision. Deployment acceptance requires the existing release gates and actual provider prerequisites.
