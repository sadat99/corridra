# ADR-023: Global markets and pinned route versions

Status: implemented for V2 Part 01; release evidence is separate.

Use the controlled global country and currency registries, distinct market scope kinds and tenant-owned directional routes. Preserve the original corridor table and historical country/market text. EU is a bloc with dated membership, never a country or inherited compliance approval. Extending country pairs is configuration data, not geographic code forks.

Publish immutable effective-dated packs through privileged configuration services. Resolve global/corridor/route/type/mission inputs by intersecting permissions and unioning obligations. Historical assignments pin exact pack/type versions. Backfill legacy missions as unresolved rather than guessing origin. Non-country scope administration remains controlled reference-data work; ordinary country-pair configuration needs no migration.

The bounded configuration schema avoids a general rules engine. Seed drafts make no coverage claim. Existing authentication, purpose/classification/country RLS and synthetic restrictions remain authoritative. See [architecture](../architecture/multi-corridor-v2.md).
