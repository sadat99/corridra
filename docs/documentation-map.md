# Documentation catalogue

[Start here](START_HERE.md) is the developer entry; [current-plan.md](implementation/current-plan.md) is current programme status. This catalogue classifies every Markdown document under `docs`. It does not replace full requirements or executed verification. JSON rollout/validation files and image/log evidence are dated snapshots; preserve their recorded hashes/results. Root/nested AGENTS govern editing; package READMEs describe module boundaries.

Immutable sources/working copies and frozen evidence were intentionally not rewritten. Historical scope/release packets retain detailed original context under clear status notices. Provider settings, test counts, deployment URLs and next-step prose in historical packets are not today's status. Current operational guides link to the reconciled handoff.
