What the pictures show
  registrations-before-<width>-<rows>row.png  origin/main 76066ca (participant-account.tsx as merged)
  registrations-after-<width>-<rows>row.png   this branch
  Widths 390 (viewport 844 high), 768 (1024 high), 1440 (900 high). One row is the default state; two rows shows the
  spacing between rows.

How they were taken
  The real ParticipantAccount, the real stylesheets (globals, shells, page-frame, overflow-menu, page-budget,
  participant-account) bundled with esbuild into a fixture page inside WorkspaceShell with the customer frame and the
  page frame, the participant API answered by the test (sample data, no sign-in, no server). Production bundle React,
  all details closed, sample mode. Same fixture, same data, before and after.

  Whole page against the window: 1.00 screens at every width and row count before and after, because the signed-in
  shell is at least one window high (document height equals the window). The content alone is 0.58 to 0.98 of a window.
  Only 390 x 2 rows is longer than before (+11 px, 0.013 of a phone screen): the owner's 24 px between rows is 12 px
  more than the old 12 px between rows, and the row menu is a 44 px target on a phone. It stays under the phone limit.
