## APPROACH
apps/web/app/page.tsx becomes async and reads `uxSwitchOn('CORRIDRA_UX_HOME_V42')` (exactly "true"). Off: returns the same `<HomeRoutes>` tree as today. On: returns new client composition `HomeV42` through a conditional `await import('../components/home-v42')` so v4.2 code and CSS load only when on. The footer switch is read where the footer switches are already read: `SiteFooter` (server) passes `homeV42` to `SiteFooterPlace`, then to `SiteFooterView` as `trim` (default false, markup unchanged when off). HomeV42 reuses live pieces: home-route radio group, ctaWords, routeHref, HomeBrief, HomeShared, TalkLink; live components change only by optional props whose defaults reproduce today's output, plus `export` on China, Delegation, Other (and Door). Rejected: forking HomeRoutes or branching inside it; drawing the hero diagram as an SVG with image and text (use an HTML list with CSS connectors: flat, tokens only, real Flag component and real text).

## HOW EACH ITEM IS BUILT
- Choice-card lines: always one line. `.hv42-line {display:flex; flex-wrap:nowrap; white-space:nowrap; align-items:center; gap:var(--space-2)}`. Do NOT reuse `.ux-route-line` (flag.css; inline-flex, wrap by design, shared) and do not edit it. Content: plain text "Bangladesh" (`home.country.bd`), verb key, then `<Flagged>` places (China via `home.country.cn`; demand: `home.tr.mk.eu/gb/us/au`). Fit: the card label gets `container-type:inline-size`; container queries step the font through tokens (--text-base, --text-sm, --text-xs) and shrink the scoped flag size (`.hv42 .ux-flag` in rem). No horizontal scroll. 320 px: estimate says the demand line (about 291 px) may not fit roughly 250 px of content at --text-xs: CONDUCTOR DECISION: try shrinking flags below 22 px at the narrowest width first (b); if it still does not fit by measurement, at the narrowest width show "sells to [flags]..." because the "Demand side" label already names Bangladesh (a). Never a horizontal scroll; the one-line assertion must hold at 320, and the measured choice is recorded in the PR.
- Stacking: `.hv42-choices` one column by default, two columns from `min-width:68.75rem` (1100 px); below that the two big cards stack, the small cards stack too at 767 px and below.
- Hero diagram: a `<ul>` of five rows: a Bangladesh node left, a CSS bus line and connectors in `--border-strong` (aria-hidden), five destination nodes (China, EU, UK, US, Australia), each a Flagged name. `role="group"` with aria-label = `home.country.bd` + `home.b3.to` + the five place names joined by commas; no new key. No Key Asian Markets node; headline and paragraph keep "key Asian markets" in the paragraph. Sphere and mark dropped.
